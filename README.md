# Watershed Delineation and Terrain Features

[**Try the Interactive Web Page**](https://biswashk920.github.io/watershed-delineation/)

This project turns a user-selected outlet and elevation dataset into a watershed
and a set of useful terrain and hydrology maps. The workflow is built around
Jupyter notebooks, so you can follow the processing step by step and inspect
the results as they are created.

Once the watershed has been delineated, getting the feature maps is quick and
repeatable: run the feature notebook, and it reuses the DEM and flow products
already generated by the delineation workflow instead of starting the
hydrology processing from scratch. Each feature is saved as a watershed-clipped
GeoTIFF and a ready-to-share PNG figure. The notebook also creates a stream
network GeoPackage.

## Requirements

- Python 3.11
- A Google Earth Engine account with access to the Copernicus GLO-30 DEM
- The Python packages listed in [`requirements.txt`](requirements.txt)

Create an environment and install the dependencies:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

On macOS or Linux, use:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Run the workflow

Start JupyterLab from the project root:

```bash
jupyter lab
```

Run the notebooks in order:

1. **[`notebooks/01_GEE_Data_Acquisation.ipynb`](notebooks/01_GEE_Data_Acquisation.ipynb) — Get the elevation data.**
   Authenticate Earth Engine when prompted. On the interactive map, draw one
   rectangle that contains the full catchment with a generous buffer, then
   place one outlet point inside it. The notebook downloads the Copernicus
   GLO-30 DEM and saves the input geometries. Large downloads are subdivided
   and mosaicked automatically.
2. **[`notebooks/02_watershedDelineation.ipynb`](notebooks/02_watershedDelineation.ipynb) — Delineate the watershed.**
   The notebook chooses a suitable UTM zone, prepares the DEM, calculates flow
   direction and accumulation, snaps the outlet to a nearby high-accumulation
   cell, delineates the upstream watershed, and clips the DEM to its boundary.
3. **[`notebooks/03_Features_of_Watershed.ipynb`](notebooks/03_Features_of_Watershed.ipynb) — Explore the watershed features.**
   Run the cells to create the terrain and hydrology maps below. The notebook
   loads the prepared watershed DEM and reuses the flow products from notebook
   02. Each feature cell saves its raster and 240-dpi PNG; the stream-network
   cell also saves a GeoPackage.

The Earth Engine account must be authorized on the machine running notebook 01.
Depending on the account configuration, Earth Engine may also require a
registered Cloud project when it is initialized.

## Outputs

The workflow writes its files into three project folders:

- `Input Data/` contains the selected area, outlet, and downloaded source DEM.
- `Preprocessing/` contains intermediate DEMs, flow rasters, and the snapped
  outlet used during delineation.
- `Output Data/` contains the watershed boundary and clipped DEM, plus:
  - `feature_layers/` — watershed-clipped feature GeoTIFFs.
  - `feature_figures/` — PNG maps shown in the gallery below.
  - `feature_vectors/` — the stream-network GeoPackage.

Generated rasters and vectors are excluded from Git; PNG figures are kept so
they can be viewed directly in the repository. See [`.gitignore`](.gitignore).

## Feature map gallery

The figures below follow the order of the feature notebook. Each map is clipped
to the watershed, so areas outside the basin are transparent.

### Terrain

#### Elevation

Elevation is the land-surface height above the raster's vertical datum. It
provides the basic context for interpreting relief, drainage, and where water
is likely to move across the basin.

![Elevation](Output%20Data/feature_figures/elevation.png)

#### Slope

Slope measures how steep the land is, in degrees. Steeper ground can encourage
faster runoff and erosion, while gentler slopes are more likely to slow water
and collect sediment.

![Slope in degrees](Output%20Data/feature_figures/slope_deg.png)

#### Aspect

Aspect is the compass direction that a slope faces. It helps compare
sun exposure, vegetation and snow conditions, and other processes that vary
with slope orientation.

![Aspect](Output%20Data/feature_figures/aspect.png)

#### Profile curvature

Profile curvature describes whether the land surface bends along the direction
of slope. It helps identify places where flow may accelerate or decelerate and
where erosion or deposition may be more likely. Curvature sign conventions can
vary between tools.

![Profile curvature](Output%20Data/feature_figures/profile_curvature.png)

#### Plan curvature

Plan curvature describes surface bending across the slope. It helps reveal
converging terrain that gathers flow and diverging terrain that spreads it out,
which is useful for understanding runoff pathways and erosion patterns.

![Plan curvature](Output%20Data/feature_figures/plan_curvature.png)

#### Hillshade

Hillshade simulates illumination across the terrain to make ridges, valleys,
and landforms easier to see. It is a visual aid rather than a direct
measurement of hydrologic conditions.

![Hillshade](Output%20Data/feature_figures/hillshade.png)

#### Topographic Position Index — 300 m neighbourhood

TPI compares each elevation cell with the average elevation in its surrounding
neighbourhood. Positive values mark locally higher ground and negative values
mark locally lower ground. The 300 m neighbourhood emphasizes smaller
landforms such as local ridges and hollows.

![Topographic Position Index, 300 m](Output%20Data/feature_figures/tpi_300m.png)

#### Topographic Position Index — 1 km neighbourhood

This TPI uses a broader 1 km neighbourhood to show larger terrain positions.
Comparing it with the 300 m map helps distinguish local features from broader
valleys, slopes, and uplands.

![Topographic Position Index, 1 km](Output%20Data/feature_figures/tpi_1km.png)

#### Terrain Ruggedness Index

The 3-by-3 Terrain Ruggedness Index (TRI) summarizes elevation differences
between a cell and its immediate neighbours. Higher values indicate rougher,
more uneven terrain, which can affect access, runoff, and erosion.

![Terrain Ruggedness Index, 3 by 3 cells](Output%20Data/feature_figures/tri_3x3.png)

#### Relative relief

Relative relief here is the local elevation range (maximum minus minimum) in a
1 km neighbourhood. It highlights how much terrain variation occurs nearby and
helps distinguish comparatively smooth areas from rugged ones.

![Relative relief, 1 km neighbourhood](Output%20Data/feature_figures/relative_relief_1km.png)

### Hydrology

#### Flow accumulation

Flow accumulation is shown as the upstream contributing area in square
kilometres. Larger values identify places receiving runoff from more of the
basin and help outline the drainage network.

![Flow accumulation in square kilometres](Output%20Data/feature_figures/flow_accumulation_km2.png)

#### Stream network and Strahler order

The stream network is extracted where contributing area exceeds 25 km².
Strahler order describes the hierarchy of tributaries: when two streams of the
same order meet, the downstream order increases. The map uses wider lines for
higher-order streams. The corresponding vector network is saved as a
GeoPackage in `Output Data/feature_vectors/`.

![Stream network coloured and weighted by Strahler order](Output%20Data/feature_figures/stream_network_25km2.png)

#### Distance to river

This map gives the straight-line distance from each watershed cell to the
nearest mapped stream. It can help identify areas close to channels, although
it does not represent the route water travels over the land surface.

![Distance to river](Output%20Data/feature_figures/distance_to_river.png)

#### Height Above Nearest Drainage (HAND)

HAND measures the elevation of each cell relative to its nearest drainage
channel. Lower values indicate land closer in height to the drainage network,
which can help screen for potentially flood-connected areas; it is not, by
itself, a flood prediction.

![Height Above Nearest Drainage](Output%20Data/feature_figures/hand.png)

#### Downstream flow length to outlet

This layer estimates the distance along the drainage path from a cell toward
the watershed outlet. It helps compare how far locations are from the outlet
along the flow network, rather than by straight-line distance.

![Downstream flow length to outlet](Output%20Data/feature_figures/downstream_flow_length.png)

#### D-infinity specific catchment area

Specific catchment area represents the upslope contributing area per unit
contour width. The D-infinity method distributes flow between downslope
directions, giving a more continuous picture of flow concentration than
assigning all flow to just one neighbour.

![D-infinity specific catchment area](Output%20Data/feature_figures/dinf_specific_catchment_area.png)

#### Topographic Wetness Index (TWI)

TWI combines contributing area and slope to indicate where terrain may favour
the accumulation of water. Higher values often occur in convergent, lower-slope
areas. It is a terrain-based wetness indicator, not a direct soil-moisture
measurement.

![Topographic Wetness Index](Output%20Data/feature_figures/twi.png)

#### Stream Power Index (SPI)

SPI combines contributing area with slope to represent the relative potential
for flowing water to exert erosive force. Higher values flag locations where
concentrated flow and steep terrain coincide.

![Stream Power Index](Output%20Data/feature_figures/spi.png)

#### Sediment Transport Index (STI)

STI is a terrain-based indicator of relative sediment transport potential,
combining information about contributing area and slope. It can help identify
areas for closer erosion assessment, but does not measure sediment movement
directly.

![Sediment Transport Index](Output%20Data/feature_figures/sti.png)

## Notes

- Draw an area of interest that includes the complete catchment and a buffer.
  The catchment must fit inside the selected area for delineation to be
  complete.
- The outlet snap search radius is currently ten DEM cells (300 m at 30 m
  resolution).
- Processing time and memory use depend on the area and resolution of the DEM.
- Do not commit Earth Engine credentials, private keys, or other secrets.
